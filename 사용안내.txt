HWP·HWPX 뷰어 v46

사용 방법
새 폴더에 압축을 풀고 index-1.html을 여세요.
상단에 v46이 표시되는지 확인한 뒤 '파일 열기'로 문서를 선택하세요.

이번 수정
Worker 생성·실행·데이터 전송이 실패해도 같은 문서 파서를 현재 화면에서
실행하는 대체 경로를 추가했습니다. 서버 업로드나 브라우저 설정 변경은 없습니다.
Worker 실패 후 재시도에 필요한 원본 바이트를 유지합니다.
정상 Worker는 기존대로 사용하며, 결과 버퍼의 소유권 전달 최적화도 유지합니다.
손상·암호화 문서의 파싱 오류 및 작업 시간 초과는 무조건 재시도하지 않습니다.
대체 작업이 시작되기 전 취소하거나 다른 문서를 열면 오래된 결과를 반영하지 않습니다.

기존 기능
원본 줄 좌표에 따른 HWP 쪽 경계 유지, 검색 및 텍스트 저장,
구역별 용지 설정, 배율 조절, PDF 인쇄, 기본 꺼짐인 뷰어 단축키를 유지합니다.

검증
첨부 HWP로 Worker 생성 실패, 비동기 실행 실패, 전송 실패 후 대체 처리를 확인했습니다.
Node 실제 Worker에서 생성된 작업 코드를 실행해 정상 전달 경로도 확인했습니다.
ZIP 대체 처리, 손상 파일 오류 표시 경로, 대체 처리 전 취소 검사를 통과했습니다.
3쪽 구조, 표 13개, 본문 보존 및 단축키 회귀 검사를 통과했습니다.

한계
사용자가 본 실제 오류 문구는 전달받지 않아 원인이 같다고 단정할 수 없습니다.
현재 브라우저 환경에서 로컬 주소 접속이 차단되어 실제 화면·인쇄는 미검증입니다.
대체 경로는 메인 스레드에서 실행되므로 큰 파일은 처리 중 화면이 잠시 멈출 수 있고,
동기 파싱 중에는 취소 버튼이 즉시 반응하지 않습니다.
계속 오류가 나면 오류 화면 전체 또는 정확한 오류 문구와 사용 브라우저를 알려주세요.
시험에 사용한 원본 HWP는 이 압축파일에 포함하지 않았습니다.
